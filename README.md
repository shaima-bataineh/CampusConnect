# CampusConnect 

A full-stack University Event Management System built to help students and companies discover, manage, and participate in university events.

## Live Demo

https://campusconnect-xt25.onrender.com

##  About the Project

CampusConnect is a web-based university event management system that provides a platform for students and companies to interact with university events.

The system supports different user roles and allows users to manage events, register for events, and search and filter available events through a responsive and user-friendly interface.

## Features

-  User Authentication
  - Student registration and login
  - Company registration and login

-  Role-Based Access Control
  - Different features and dashboards based on user role

-  Event Management
  - Create events
  - Edit events
  - View event details
  - Manage events

-  Event Registration
  - Students can register for available events

-  Search & Filtering
  - Search and filter events easily

-  User Dashboards
  - Student dashboard
  - Company dashboard

-  Responsive Design
  - Works across different screen sizes

-  Database Integration
  - SQLite database for storing users, events, and registrations
